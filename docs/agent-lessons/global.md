# 经验：通用

由 yado_agents 自动维护：自动 review 和代码清理时总结的规则。要作废请到控制台「Agent → 经验」，不要直接改这个文件。

- 清库、解绑这类后续步骤依赖其结果的写操作，不要用 try? 吞掉错误，失败要中止后续步骤（吞掉错误会让后续步骤在脏状态上继续执行）
- 校验可选环境变量时要把空字符串视为未配置，不要直接用 .min(1).optional()（在 .env 里写成 KEY= 会得到空字符串，校验失败会让服务起不来）
- 写和现有逻辑同类的校验或清洗时，先把已有代码抽成共用函数再复用，不要整段复制后改几处（复制出来的规则会慢慢分叉，改一处会漏掉另一处）
- SwiftUI 容器加标识前先加 .accessibilityElement(children: .contain)（否则会盖掉子控件的标识，UI 测试找不到按钮）
- 新增必需的 @Environment 对象要注入到根视图，或检查所有打开该页面的入口（从弹层等其他入口打开时取不到对象，App 会直接崩溃）
